Exercise 1. 일반동사 활용문

정보를 의심하는 것이 더 많은 정신적 노력을 필요로 하기 때문에, 인간은 자연스럽게 타인이 진실을 말한다고 가정한다.
1. naturally (자연스럽게) 2. assume (가정하다) 3. question (의심하다/질문하다) 4. require (필요로 하다) 5. mental effort (정신적 노력)
Humans naturally assume that others tell the truth because questioning information requires more mental effort.

Exercise 2. be동사 활용문

진실 편향은 인지적 에너지를 아끼기 위해 우리가 정보를 먼저 믿게 되는 기본 심리 상태이다.
1. truth bias (진실 편향) 2. default (기본값의) 3. psychological state (심리 상태) 4. cognitive energy (인지적 에너지) 5. save (아끼다/저장하다)
The truth bias is a default psychological state where we believe information first to save cognitive energy.
